모든 챔피언 데미지 실험실

챔피언·레벨·스킬 랭크·아이템·라인 퀘스트를 설정하고 상대 체력·방어력·마법 저항력을 바꿔 기본 공격 피해와 검증된 스킬의 1회 적중 피해를 비교해.

Riot Data Dragon 연동

1 · 챔피언 및 레벨

2 · 아이템 장착

공식 아이템의 구조화된 능력치만 계산해. 고유 지속효과·스택·특수 공격 효과는 자동 계산하지 않아.

3 · 추가 능력치 수정

룬, 버프, 아이템의 Data Dragon 누락 수치 등을 직접 입력할 때 사용해.

4 · 적 대상 설정

상대 체력 수치는 1회 피해 후 남은 체력을 계산하는 데 사용해. 이동·회피·스킬 보호막·피해 감소와 치명타 개별 효과는 제외.

5 · 계산 결과

6 · 스킬 피해 공식 검증 / 직접 입력

모든 챔피언의 Q/W/E/R 이름과 레벨을 다룰 수 있지만, 공식 Data Dragon에 신뢰 가능한 전체 스킬 피해 공식이 없는 경우 **자동 데미지를 추측하지 않아**. 해당 스킬의 실제 계수를 확인해 직접 입력하면 현재 스탯으로 계산할 수 있어.

정확도 범위: 일반 평타는 단순 방어력 계산, Riot 26.22 패치 노트로 확인된 일부 스킬은 단일 적중 공식 적용. 나머지 스킬, 모든 고유 아이템 효과·룬·연속 스킬·스택·방어막은 미지원. 자동 계산 결과를 실제 게임의 확정 피해로 취급하면 안 돼.

26.22 공식 패치 노트
RIOT ID SEARCH · MATCH HISTORY · LIVE GAME

전적 검색과 인게임 정보

서버에 Riot API 키가 연결된 뒤 정상 조회할 수 있어. 게임 중 숨겨진 정보나 경쟁상 불공정한 분석은 제공하지 않아.

API 서버 미연결

GitHub Pages와 별도로 배포한 Cloudflare Worker 주소만 입력해. API 키는 이 웹페이지에 절대 넣지 마.

전적/인게임 조회는 API 서버가 설정될 때까지 비활성 상태야. Riot Sign On 인증은 승인 및 서버 구축이 필요한 별도 기능이야.

분석 근거 및 예측의 한계

2026 월즈 패치 26.20의 공개 픽·밴 빈도, LCK 팀의 드래프트 성향 분석, 선수별 풀 자료를 참고한 가상 휴리스틱이야. 영상의 정확한 음성 설명은 확인하지 못했으며 바르암의 색상 분류만 사용자 자료로 반영했어. 김순 영상은 정확히 확인되지 않아 분석을 인용하지 않았어.

팀별 선호도는 공개 기록을 바탕으로 한 수동 예시 가중치라서 선수와 감독의 실제 선택을 그대로 예측하지 않아. 승률, 경기 결과, 정글 주도권은 생성하지 않고 밴픽 선택 이유만 제공해.
