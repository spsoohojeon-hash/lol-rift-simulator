# ⚔️ 협곡 연구소 / LOL Rift Simulator

**비공식 League of Legends 교육·실험용 웹앱.** React/서버 없이 GitHub Pages에서 동작하는 단일 페이지 프로젝트.

## 바로 실행하기
- GitHub Pages를 사용한다면 Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
- 배포 주소(활성화된 경우): https://spsoohojeon-hash.github.io/lol-rift-simulator/
- 로컬에서는 `index.html`을 브라우저로 열어 사용 가능. 챔피언 아이콘·한국어 명단을 불러오려면 인터넷 연결이 필요하다.

## v0.3~v0.5 지원 기능

### 1. 피어리스 밴픽
- BO3 / BO5 시리즈 선택
- **토너먼트 순서 20단계**: 밴 1차 B-R-B-R-B-R → 픽 1차 B-R-R-B-B-R → 밴 2차 R-B-R-B → 픽 2차 R-B-B-R
- 시리즈 이전 세트에서 **양 팀이 픽한 챔피언만** 이후 세트에서 선택 금지 (Hard / Full Fearless)
- 매 세트의 일반 밴은 다음 세트로 이월되지 않음
- 세트 기록 열람·현재 세트 되돌리기·픽한 챔피언의 역할(라인) 재지정·JSON 내보내기·브라우저 로컬 저장
- Riot Data Dragon 최신 한국어 챔피언 목록 및 공식 이미지, 실패 시 기본 명단

### 2. 협곡 실험 엔진 (초기 구현)
- 임의 챔피언(최대 10명) 및 팀/라인/레벨 지정 후 맵 클릭 배치
- 밴픽 중인 현재 세트 챔피언을 협곡으로 가져오기
- 3개 라인의 미니언 웨이브 자동 생성(시각 시뮬레이션, 1:05부터 30초 간격), 수동 생성
- 도식화한 3라인 이동 경로 및 간이 포탑·정글 몬스터·오브젝트 등장/피해·리스폰
- 근사 모델로 기본 공격·방어력 계산, HP 감소, 사망 및 일부 AI 타깃 선택
- 클릭으로 이동 및 목표 공격, 재생·일시정지·속도 배수·시간 스텝
- 기절·속박·에어본·둔화·침묵·제압·공포·매혹 상태를 부여하고 지속시간 추적
- 와드 배치, 유닛 선택, 삭제, 상황 로그

## 바르암 가속도 분류

| 색상 | 뜻 |
|---|---|
| 빨강 | 가속 |
| 보라 | 상대에 따라 가속 또는 브레이크를 결정 |
| 파랑 | 브레이크 |
| 노랑 | 성장 |
| 초록 | 탱 |

영상 캡처에서 식별이 확실한 일부 챔피언만 **잠정** 분류한다. 오류가 많았던 옛 자동 분류는 제거했다. 상대 조합이나 빌드에 따라 달라지는 경우 또는 얼굴을 확실히 식별할 수 없는 경우는 미분류 상태로 둔다. 분류 수정 UI로 챔피언/포지션별 태그를 사용자가 변경할 수 있으며 변경 사항은 해당 브라우저에 보관한다. **이 분류는 Riot 공식 티어/승률 데이터가 아니다.**


## v0.4 — 2026 월즈/팀별 자동 피어리스 밴픽 (NEW)

상단의 **AI 코치 자동 밴픽**에서 두 팀을 정하면 한 턴, 현재 세트, BO3/BO5 전체를 자동 생성할 수 있다.

- 지원 팀: LCK **GEN·T1·HLE·DK**, LPL **BLG·TES·IG·AL** (2026 월즈 진출 8팀)
- 월즈 2026 **패치 26.20** 데이터 스냅샷 기준: 2026-11-03 공개 통계, 73게임 사례. 메타 우선순위는 주로 관측된 픽/밴 횟수에서 출발.
- 전술 모드: 균형 / 가속 / 브레이크 / 성장. 가속 유형(빨강), 상대 의존형(보라), 브레이크(파랑), 성장(노랑), 탱(초록)은 사용자 제공 바르암 분류표의 **미확정 전사**만 작은 보정값으로 사용.
- 팀별 선수 챔피언 풀과 빈번한 밴 패턴을 바탕으로 한 **수작업 가중치 모델**, 챔피언-라인 보완, 아군 콤보, 상대 진입 대응, 금지된 챔피언 제외.
- 선택 이유 기록, 밴픽 JSON 내보내기, 기존 자유 밴픽과 혼합 사용 가능.
- 시드 및 변동성으로 재현 가능한 다른 시나리오 생성. **기본 2026 시드에서 재현 가능**.
- Full Fearless: 앞선 게임 픽은 양 팀 모두 재사용 불가. 밴은 다음 게임에 이월되지 않음.
- BO 전체 생성은 **승패를 시뮬레이션하지 않으며**, 최대 3 또는 5게임을 모두 만든다. 수치들은 승률·예측 확률이 아니다.
- 팀 프로필 특히 LPL 세부 드래프트 성향은 일부 팀별 공개 자료의 한계를 보완하려는 모델 가정이다. 실제 감독·선수의 선택을 주장하지 않는다.
- **바르암**은 사용자 제공 분류표의 색상 정의만 확인하여 반영했다. **김순 영상**의 발언/내용은 직접 검증되지 않아 인용하거나 모델에 임의로 추가하지 않았다.

## v0.5 — 라인 주도권 / 정글 합류 / 협곡 교전 실험 (NEW)

상단 **라인·정글 분석** 탭에서 현재 세트의 10픽을 자동으로 가져와 다음을 비교한다.

1. **TOP / MID / BOT 라인 주도권:** 개발자가 작성한 초반 교전·웨이브 정리·원거리 견제 특징값과 Data Dragon 기본 스탯으로 블루−레드 **상대 비교 지수**를 만든다. **승률 아님.** 불완전한 픽은 계산 불가로 표시한다.
2. **정글 동선:** 각 팀별 3캠프·6캠프 5개 코스, 순서·캠프별 근사 소요 시간·라인 도착 예상 시각·합류 기회 가중치를 계산한다. 협곡 지도에 실제 경로 선을 그리는 기능이 있다.
3. **2대2 / 3대3 기본 교전:** 상단 챔피언 능력치와 임시 진입·보호 태그를 비교한다. **선택한 교전 협곡에 배치**를 누르면 게임 중 시간이 해당 동선의 가상 합류 타이밍으로 맞춰지고, 챔피언을 배치한 뒤 ▶ 재생으로 **실제 공격 엔진의 HP 감소와 처치 상황**을 실험할 수 있다.
4. JSON으로 분석값을 내보낼 수 있다. 분석값은 모든 조건이 같으면 같은 값을 반환한다.

### 2026 시즌 시간 기준

- [Riot 공식 26.1 패치 노트](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-26-1-notes/)에 따라 **미니언 0:30**, 주요 정글 캠프 **0:55**, 두꺼비·돌거북 **1:07**, 바론 **20:00**을 기본 타이밍으로 채택했다.
- 정글러별 실제 평균 풀캠 시간은 [KO.LOL full clear 기록](https://ko.lol/ko/data/clear-time/)에서 크게 다르므로, 실험 엔진의 개별 캠프 시간은 아직 **고정 근사 모델**이다. 해당 데이터의 실측 시간을 그대로 모델에 복사하거나 실제 경기 성공률처럼 설명하지 않는다.
- 봇·탑 라인 주도권 수치는 스킬·미니언 어그로·라인상성 데이터까지 연결한 확정 수치가 아니며 **개발용 지표**에 불과하다.
