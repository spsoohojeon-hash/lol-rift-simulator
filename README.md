# ⚔️ 협곡 연구소 / LOL Rift Simulator

**비공식 League of Legends 교육·실험용 웹앱.** React/서버 없이 GitHub Pages에서 동작하는 단일 페이지 프로젝트.

## 바로 실행하기
- GitHub Pages를 사용한다면 Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.
- 배포 주소(활성화된 경우): https://spsoohojeon-hash.github.io/lol-rift-simulator/
- 로컬에서는 `index.html`을 브라우저로 열어 사용 가능. 챔피언 아이콘·한국어 명단을 불러오려면 인터넷 연결이 필요하다.

## v0.3 지원 기능

### 1. 피어리스 밴픽
- BO3 / BO5 시리즈 선택
- **토너먼트 순서 20단계**: 밴 1차 B-R-B-R-B-R → 픽 1차 B-R-R-B-B-R → 밴 2차 R-B-R-B → 픽 2차 R-B-B-R
- 시리즈 이전 세트에서 **양 팀이 픽한 챔피언만** 이후 세트에서 선택 금지 (Hard / Full Fearless)
- 매 세트의 일반 밴은 다음 세트로 이월되지 않음
- 세트 기록 열람·현재 세트 되돌리기·픽한 챔피언의 역할(라인) 재지정·JSON 내보내기·브라우저 로컬 저장
- Riot Data Dragon 최신 한국어 챔피언 목록 및 공식 이미지, 실패 시 기본 명단

### 2. 협곡 실험 엔진 (초기 구현)
- 임의 챔피언(최대 10명) 및 팀/라인/레벨 지정 후 맵 클릭 배치
- 밴픽 중인 현재 세트 챔피언을 협곡으로 가져오기
- 3개 라인의 미니언 웨이브 자동 생성(시각 시뮬레이션, 1:05부터 30초 간격), 수동 생성
- 도식화한 3라인 이동 경로 및 간이 포탑·정글 몬스터·오브젝트 등장/피해·리스폰
- 근사 모델로 기본 공격·방어력 계산, HP 감소, 사망 및 일부 AI 타깃 선택
- 클릭으로 이동 및 목표 공격, 재생·일시정지·속도 배수·시간 스텝
- 기절·속박·에어본·둔화·침묵·제압·공포·매혹 상태를 부여하고 지속시간 추적
- 와드 배치, 유닛 선택, 삭제, 상황 로그

## 바르암 가속도 분류

| 색상 | 뜻 |
|---|---|
| 빨강 | 가속 |
| 보라 | 상대에 따라 가속 또는 브레이크를 결정 |
| 파랑 | 브레이크 |
| 노랑 | 성장 |
| 초록 | 탱 |

영상 캡처에서 식별이 확실한 일부 챔피언만 **잠정** 분류한다. 오류가 많았던 옛 자동 분류는 제거했다. 상대 조합이나 빌드에 따라 달라지는 경우 또는 얼굴을 확실히 식별할 수 없는 경우는 미분류 상태로 둔다. 분류 수정 UI로 챔피언/포지션별 태그를 사용자가 변경할 수 있으며 변경 사항은 해당 브라우저에 보관한다. **이 분류는 Riot 공식 티어/승률 데이터가 아니다.**

## 현재 한계 및 다음 과제
- 2D 도식 지형이며 실제 협곡 충돌·시야·거리 및 패치 규칙을 그대로 복제한 것이 아님
- 챔피언별 Q/W/E/R, 소환사 주문, 아이템, 룬, 투사체 및 전체 CC 세부 상호작용 미구현
- 멀티플레이어 실시간 밴픽(상대방 링크로 접속)은 미구현. 현재는 **한 브라우저에서 양 팀을 조작하는 연습용**
- 실제 가속도 점수·교전 승률·정글 가용성은 아직 계산하지 않음
- 향후: 공식 챔피언 수치 적용 → 정밀 전투 엔진 → 미니언 타깃팅/포탑 → 정글 동선 및 합류 타이밍 → 리플레이
