# LOL Rift Simulator / 협곡 연구소

리그 오브 레전드 밴픽과 협곡 운영을 실험하기 위한 비공식 팬 프로젝트입니다.

## 실행
루트의 `index.html`을 브라우저에서 열면 됩니다. GitHub Pages 설정 후 웹에서 바로 사용할 수 있습니다.

## 현재 단계
- 밴픽 시뮬레이터: 포지션별 블루/레드 진영 자유 픽, 밴, 검색, 분류별 조합 집계
- 브라우저 로컬 저장
- 정글 가속도 분류: 빨강=가속, 보라=상대에 따라 가속·브레이크, 파랑=브레이크, 노랑=성장, 초록=탱
- 캡처를 기준으로 한 분류는 잠정적이며 게임 공식 분류나 승률 지표가 아닙니다.

## 개발 로드맵
1. 챔피언 전체 명단/드래프트 밴픽 순서/스왑
2. 정글 캠프/동선/레벨·골드 및 템포 모델
3. 미니언 웨이브, 프리징, 슬로우푸시, 바운스
4. 이동/평타/스킬/CC/아이템 계산
5. 10인 전투/시야/오브젝트/리플레이

공식 게임 데이터가 아닌 모델의 추정 결과는 명확히 구분합니다. Riot Games와 무관한 비공식 도구입니다.
